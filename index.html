Semi Buildout → Semi Supply — Edge Math

What Is Being Modeled

This formula is intended to model the behaviors between forces in the world as simply and accurately as possible. It is naive to assume there are fully deterministic relationships between geopolitical forces, but for the sake of the OGE platform, these relationships are the basis on which decisions can be made and examined. What matters most is decision analysis based on given information — the accuracy of the model is a plus, not a requirement for OGE success.

A stock is any measurable quantity that exists in the world and changes over time — here, domestic semiconductor buildout capacity and trusted semiconductor supply. An edge is a causal relationship between two stocks: when one changes, it eventually pushes the other. A player decision directly sets the value of a source stock. That changed value then propagates to a target stock after a delay called the lag.

How Values Change Over Time

Each stock's value is shown at every tick on the number lines below. The source stock (Semi Buildout) jumps when the player makes a decision. The target stock (Semi Supply) stays flat during the lag window — it does not respond until the lag is fully elapsed. Once the lag fills, supply begins moving toward a new equilibrium.

How the Math Works

Three formulas govern what happens each tick. The first compresses the source stock's deviation so that large moves have diminishing influence. The second sets the equilibrium value the target stock is trying to reach. The third moves the target stock a fixed fraction of the remaining distance toward that equilibrium each tick.

Step 1 — Measure how far the source stock has moved from its own baseline:
buildout_deviation_from_baseline = buildout_current_value − buildout_baseline_value
This tells us how much the source stock has been displaced. A stock at its baseline has deviation = 0 and exerts no pull on the target. Step 2 — Compress that deviation through the saturation function:
squash(buildout_deviation_from_baseline) = SAT_A · tanh(buildout_deviation_from_baseline / SAT_A)
Saturation prevents extreme deviations from having unlimited influence. No matter how large the deviation grows, the squash result is capped near SAT_A = 38. Small deviations behave nearly linearly; large ones flatten out. Step 3 — Compute the equilibrium value the target stock is being pulled toward:
supply_equilibrium_value = supply_baseline_value + edge_weight · squash(buildout_deviation_from_baseline)
This is the value supply would reach if given infinite ticks with no other changes. It stays fixed as long as buildout's deviation doesn't change. Step 4 — Move the target stock a fraction of the remaining gap each tick:
supply_value_next_tick = supply_current_value + α · (supply_equilibrium_value − supply_current_value)
α = 0.3 means each tick closes 30% of whatever gap remains between the current value and the equilibrium. The steps get smaller every tick — the stock approaches exponentially, never overshooting.

Variable Reference

Every variable used in the formulas below, with its definition and value in this example.

buildout_current_valueThe value of Semi Buildout at the current tick. Jumps to 60 at tick 1 when the player decision takes effect.
buildout_baseline_valueThe resting value of Semi Buildout before any decision is made. In this example: 20.
buildout_deviation_from_baselineHow far Semi Buildout has moved from its own baseline. = buildout_current_value − buildout_baseline_value. In this example: 60 − 20 = 40. A stock at its baseline has deviation = 0 and exerts no pull on the target.
SAT_AThe saturation constant. Caps the maximum influence any single edge can exert regardless of how extreme the deviation gets. In this example: 38.
squash(buildout_deviation_from_baseline)The deviation compressed through the saturation function: SAT_A · tanh(deviation / SAT_A). Applies diminishing returns — large deviations keep contributing, but with decreasing effect. In this example: ≈ 29.8.
edge_weightThe strength of the causal relationship between Semi Buildout and Semi Supply. Scales how much of the squashed deviation reaches the target. In this example: 0.6.
supply_baseline_valueThe resting value of Semi Supply when no edge is pushing it. In this example: 40.
supply_equilibrium_valueThe value Semi Supply would reach if given infinite ticks at the current buildout level. The destination the stock is moving toward. Stays fixed as long as buildout's deviation doesn't change. In this example: ≈ 57.9.
supply_current_valueThe value of Semi Supply at the current tick, before this tick's update is applied.
α (alpha)The fraction of the remaining gap between supply_current_value and supply_equilibrium_value that is closed each tick. In this example: 0.3 (30% per tick).
supply_value_next_tickThe value Semi Supply will have at the start of the next tick, after this tick's update is applied.

Full Derivation — Tick 6 → 7 (First Delta)

The lag is 5 ticks. The decision takes effect at tick 1. So the first tick at which the lag window is fully filled is tick 6 — when the engine looks back 5 ticks and finds buildout already at 60. This is the first tick where supply changes.
